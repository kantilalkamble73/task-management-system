# Task Management System
A web-based Task Management System developed using Java, Spring Boot, MySQL, Thymeleaf, and Bootstrap. The application helps users efficiently create, manage, update, and track tasks through a simple and user-friendly interface.

## Features
- Add, update, and delete tasks
- Search tasks by title
- Dashboard statistics
- Dark mode support
- Due date alerts
- User authentication and security
- Responsive UI

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Bootstrap
- Maven
- Git & GitHub

## Project Structure
- MVC Architecture
- Database Integration with MySQL
- Secure Authentication
- Responsive Frontend Design
